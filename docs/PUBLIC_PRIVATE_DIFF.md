# 扩展版与原工程的精确差异

初版文字核心只覆盖了原工程的一部分。图片入站、引用、本人文本缓存、processing / typing、通知和合并读取都有可通用化实现；将它们排除是当时的范围缩减，并不是它们只能属于某个个人实例。

扩展版将这些业务逐项补入，另外设计图片出站与显式本地绑定流程。此页与 [能力矩阵](CAPABILITIES.md) 一起维护：代码具备、默认开启、本地合成验证、真实云端验证是四种不同状态。本树已通过有界本地测试、mock demo 与运维命令验收；下面的代码现状不代表已完成真实微信验证。

## 业务能力

| 能力 | 原成熟工程 | 初版文字核心 | 扩展版处理 |
| --- | --- | --- | --- |
| 文本入站与一次 final | 有 | 有 | 保留并作为共同安全底座 |
| PNG/JPEG 入站 | 有固定 CDN 下载、解密、原生图片输出 | 无 | 恢复通用媒体读取 |
| 图片出站 | 未发现对应上传与发送模块 | 无 | 新增 image-only final，拒绝 caption，与文字共用 claim；不能冒称原功能已迁移 |
| 入站 inline 引用 | 有，不可信字段投影 | 无 | 恢复引用内容与来源状态 |
| 本人文本引用缓存 | 有，需显式同意，一小时/容量限制 | 无 | 通过新部署的明确开关启用；不复制旧同意证据 |
| 引用式文本 final | 有，以原消息 ID 构造 ref_msg | 无 | 恢复；图片的文本引用仍不是图片发送 |
| processing / typing | 有独立状态、lease 与有限提示 | 无 | 恢复通用模块；不宣称模型执行或 UI 可见性 |
| 主动通知与查询 | 有独立授权、context 与账本 | 无 | 恢复；新部署自行选择本地 context 策略 |
| 提供方启动生命周期通知 | real 轮询前有一次启动通知 | 无 | 提供默认关闭的显式开关；不是发给本人的聊天通知 |
| 最多三条合并读取 | 有末次全批复核与图片索引 | 无 | 恢复，并为隔离 mock 提供对应合成验证 |
| 临时文字确认 | 有代码，但成熟配置关闭 | 无 | 可选阶段默认关闭；不会把“完整”理解为自动多发消息 |
| 微信绑定 | 有手动 QR 状态机与管理入口 | 仅离线导入 | 独立本地显式流程；不暴露为入站可触发的 MCP 登录工具 |

默认关闭的可选项不等于没有代码，也不表示该用户已经同意开启。通知、缓存和额外发送各自的条件必须明确。

## 架构与平台适配差异

| 项目 | 原工程依赖 | 扩展版边界 |
| --- | --- | --- |
| 宿主身份 | 特定平台的 OAuth / 可信用户分发 | 通用固定用户 JWT 资源验证；外部身份层未内置，不能信任公网伪造 header |
| 网站绑定页面 | 已认证网页、原 owner、同源请求、CSRF 与 cookie | 采用显式本地绑定流程；没有交付等价的 Sites 网页适配器 |
| 状态与路由 | 平台状态库及业务服务协同 | Node 与本地 SQLite；不需要平台状态库，但不提供其接口替身 |
| 同一入口 mock / real | 独立 mock 业务与真实业务，经受控路由统一入口 | 仍采用一个进程一种 mode、各自状态目录；这不是同入口双模式的完整复制 |
| 在线平台迁移 | 写入栅栏、冻结、状态摘要、激活回执、旧调用防写 | 只提供单机代码切换与 writer lock；没有实现等价的跨平台迁移工具 |
| 回滚 | 与原平台拓扑、状态和权限配合 | 仅验证同 schema 扩展副本，不还原数据库；当前脚本拒绝跨 schema 切换，扩展 schema 2 与旧文字 0.1 运行时互拒 |
| 部署身份与订阅 | 某个私有实例的既有配置和授权 | 新部署必须自行获得宿主资格、身份服务与订阅，旧权限不可复制 |
| dot 素材字节获取 | 依赖具体宿主工具与授权 | 桥只收 base64 PNG/JPEG；本树不内置 Library / 图片生成素材导出适配器 |

这些平台能力不是“私人功能”。其业务原则可以通用化，但运行需要真实平台支持、适配代码及独立测试。本树没有实现的适配会作为缺项保留，而不是被“通用 Node 已能运行”覆盖。

旧文字版到扩展版不是已提供的数据迁移路线。不能以新空库复用原绑定来绕过兼容性拒绝；迁移必须保留旧 ledger、final claim 和 uncertain 历史，所需专门流程尚未提供。

## 新部署不能继承的内容

本人账号、签名密钥、真实 callback、OAuth 连接、域名、历史消息、截图、日志和授权证据均不随源码提供。原通知 context 的授权时长也不能直接成为所有新部署的默认授权。

引用缓存的同意需由新部署者明确作出，不再依赖某条旧消息。通知 context 保留多久是本地策略，提供方有效期仍未知。图片本地测试使用合成字节与 stub，不会调用某个已有账号的 CDN 权限。

## 仍未实现或未验收

群聊、多账户、语音、视频、文件以及任意微信历史查询，在本次核查的原成熟桥接中也没有完整实现。它们应作为新功能单列，不能靠 Tencent 上游的功能名称推断本项目支持。

扩展版尚未做真实宿主订阅、真实二维码绑定、真实微信图片或通知收发验收。本地合成测试验证模块和状态机，不证明平台已唤醒原 dot、客户端显示 typing、引用在 UI 可见，或图片已成功送达。

这里不发布旧环境的性能数字，也不承诺十秒响应。新媒体、通知和状态调用可能增加网络等待；它们的功能正确性与端到端响应速度应分别验证。
