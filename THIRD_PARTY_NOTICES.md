# Third-party references and runtime

This preparation candidate contains no vendored npm packages, Node.js binary, OpenClaw installation, Tencent plugin distribution, or Sites website template. The final audit checks the actual file tree and import inventory; this statement must be reconsidered if dependencies are added.

The final provenance audit must identify any directly copied code or asset and retain its applicable copyright and permission notice. Protocol compatibility is separate from copying an implementation. |

This archive does not redistribute Node. A distributor who later bundles a runtime must review that exact distribution and retain its required notices. |
| [MCP specification](https://modelcontextprotocol.io/specification) | Protocol reference | No MCP SDK package or specification text is vendored. |

Names identify compatibility references only. They do not imply endorsement, sponsorship, account eligibility, or permission to bypass any service's access controls.

Synthetic media used in local tests is generated by test code. No Weixin message, photograph, captured QR code or third-party image asset belongs in this source distribution. Node supplies the cryptographic and compression primitives; the archive does not include a separate codec or cryptography package.
